# KPL Official starter

This is the first frontend stage for KPL Official.

Next stages:
1. Firebase project
2. Google Authentication
3. Firestore data model
4. Admin authentication/roles
5. Tournament management
6. Registration system
7. Private document storage
8. Manual UPI/QR/UTR payment flow
9. User dashboard
10. Cloudflare Pages + kplofficial.com

The current site is static and can be previewed by opening index.html.

Firebase Google Authentication is now wired into the static frontend. Before production, add the final public domain to Firebase Authentication > Settings > Authorized domains.
